# روزنگار

مدیریت کارها، عادت‌ها و تمرکز با تقویم شمسی — نسخه وب (PWA) و اندروید.

## امکانات
- **امروز**: حلقه هدف روزانه، پیوستگی، عادت‌های امروز، ثبت حال روز و یادداشت، اشتراک خلاصه روز
- **کارها**: روزهای پیش رو، تقویم شمسی (با تعطیلات رسمی خورشیدی و حال هر روز)، فهرست، بُرد کانبان، ماتریس آیزنهاور
- **افزودن سریع با زبان طبیعی**: «تحویل گزارش پنج‌شنبه ساعت ۱۰ #کار !فوری ~30»
- **عادت‌ها**: برنامه روزهای هفته، پیوستگی، رکورد، نقشه سابقه برای هر عادت
- **تمرکز**: پومودورو با صدای محیطی (باران، موج، نویز سفید)، شروع خودکار مرحله بعد، روشن ماندن صفحه
- **گزارش**: نقشه فعالیت به سبک گیت‌هاب (کار / عادت / تمرکز)، امتیاز بهره‌وری و بینش‌ها
- **یادآوری**: اعلان برای کارهای ساعت‌دار و یادآور روزانه (در اندروید حتی وقتی برنامه بسته است)
- ظاهر مینیمال، پوسته روشن/تیره/خودکار، شش رنگ اصلی، سه اندازه متن، کشیدن کار برای انجام یا انتقال به فردا، لرزش لمسی
- کاملاً آفلاین؛ پشتیبان‌گیری و بازیابی JSON

## نصب روی اندروید
هر push روی گیت‌هاب با GitHub Actions یک فایل APK می‌سازد:
**Actions ← Android APK ← آخرین اجرا ← Artifacts ← `roozngar-apk`**.
با push یک تگ مثل `v2.0.0` فایل APK در بخش Releases هم منتشر می‌شود.

## توسعه
```bash
npm install
npm test            # آزمون‌های هسته (تقویم، افزودن سریع، عادت‌ها)
npm run serve       # اجرای نسخه وب روی http://localhost:8080
npm run apk         # ساخت APK (نیازمند Android SDK و JDK 21)
```
کد وب در پوشه `www/` است و پروژه اندروید (Capacitor) در `android/`.
